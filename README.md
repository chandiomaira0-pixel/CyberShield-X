# CyberShield-X

## About the Project

CyberShield-X is a C++ based cybersecurity awareness project designed to promote digital safety and help users understand common cybersecurity risks.

The project demonstrates practical C++ programming concepts while focusing on important digital security and awareness practices.

## Key Objectives

- Promote awareness of digital safety and cybersecurity.
- Help users understand common online security risks.
- Demonstrate practical application of C++ programming concepts.
- Maintain activity information through an audit log.

## Technologies Used

- C++
- Object-Oriented Programming
- File Handling
- Conditional Statements
- Loops
- Functions

## Project Files

- `CyberShield_X.cpp` — Main C++ source code
- `audit_log.txt` — Project activity log
- `CyberShield_X Extended Academic Project Report` — Detailed project report

## Purpose

CyberShield-X combines programming with cybersecurity awareness to create an educational project focused on safer digital practices.
